# BABTEK Corporate Website — Implementation Roadmap

## Approved brand direction

- Primary colour: blue.
- Supporting colours: white, charcoal and light grey.
- Homepage hero: architecture-led imagery.
- Corporate tagline: **Building a Better Future.**
- Homepage headline: **Building Ideas. Engineering Possibilities. Creating Value.**
- Domain: undecided.

## Release 1 — Corporate website

- Responsive homepage.
- Corporate profile and leadership.
- Eight division pages.
- Services catalogue.
- Projects and portfolio with status labels.
- Technology and product profiles.
- Research and innovation.
- Academy, real estate, ventures, products and supply.
- Partnerships and careers.
- Insights and news.
- Contact and project enquiries.

## Release 2 — Content and enquiry backend

- Supabase project and schema.
- Dynamic content management.
- Enquiry persistence and reference numbers.
- Enquiry routing and notification.
- Media storage and editorial controls.

## Release 3 — Secure business platform

- Authentication and user profiles.
- Client portal.
- Partner access.
- Project operations.
- Quotations, agreements and documents.
- Finance and management dashboards.

## Release 4 — Technology ecosystem

- Integrations for BABTEK software products.
- Automation and API services.
- Product-specific workspaces.

## Release gates

No production launch until contact information, company registration details, public address, legal content, project permissions and domain are verified. No product or service should be labelled operational unless that status is accurate.
